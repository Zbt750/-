一、今天踩过的坑（按时间顺序）
坑①：certbot 安装失败
报错：

Text
No match for argument: certbot
原因： 阿里云 Linux 4（Alibaba Cloud Linux）的 yum 源里没有 certbot 包

解决： 改用阿里云免费 SSL 证书，在控制台申请、下载、手动配置 Nginx

坑②：Nginx 配置被截断
现象： 执行 cat > /etc/nginx/nginx.conf << 'EOF' 时，因为内容里也有 EOF 字符串，导致 heredoc 提前结束，配置文件不完整

解决： 把结束符改成不冲突的名字，比如 NGINXEOF

Bash
cat > /etc/nginx/nginx.conf << 'NGINXEOF'
... 配置内容 ...
NGINXEOF
坑③：ERR_CONNECTION_RESET（连接被重置）
现象： 微信开发者工具请求 https://duty.yoga/auth/login 时报 net::ERR_CONNECTION_RESET

排查过程：

✅ 服务器上 curl https://duty.yoga/docs 正常返回 → 服务器没问题
✅ nslookup duty.yoga 解析到正确 IP → DNS 没问题
✅ 浏览器能打开 https://duty.yoga/docs → 证书没问题
✅ 443 端口安全组已开放 → 防火墙没问题
❌ 微信开发者工具一直报错
根本原因： 微信开发者工具与本地网络有 代理/防火墙冲突，临时解决方法：

勾选"不校验合法域名"
开发者工具设置 → 代理 → "不使用代理（直接连接）"
坑④：浏览器报 ERR_CERT_COMMON_NAME_INVALID
现象： 访问 http://121.41.20.177 被 301 跳转到 https://121.41.20.177，然后报证书错误

原因： SSL 证书只签了 duty.yoga 和 www.duty.yoga，没有签 IP 地址

解决： Nginx 配置中，IP 访问直接走 HTTP，不走 HTTPS：

Nginx
server {
    listen 80;
    server_name 121.41.20.177;
    location / {
        proxy_pass http://127.0.0.1:8000;
    }
}
坑⑤：未备案域名被阿里云拦截
现象： 中午用 https://duty.yoga 还能正常访问，晚上就不行了

原因： 阿里云检测到域名未备案，自动封锁了 80/443 端口（不是立刻封锁，有延迟）

解决： 提交 ICP 备案（7-20天），备案通过前用 http://121.41.20.177 开发测试
