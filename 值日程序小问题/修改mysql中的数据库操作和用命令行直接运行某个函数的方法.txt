| 功能 | 命令 |
|------|------|
| **生成今天的值日记录** | `python -c "from tasks.scheduler import generate_daily_records; generate_daily_records()"` |
| **固定前一天的记录** | `python -c "from tasks.scheduler import fix_previous_day_records; fix_previous_day_records()"` |
| **删除三天前的记录** | `python -c "from tasks.scheduler import delete_three_days_ago_records; delete_three_days_ago_records()"` |
| **查看所有学生** | `python -c "from database import SessionLocal; from models import Student; db = SessionLocal(); students = db.query(Student).all(); [print(f'id={s.id}, 姓名={s.name}, 学号={s.student_id}') for s in students]"` |
| **查看今天的值日记录** | `python -c "from database import SessionLocal; from models import DutyRecord; from datetime import date; db = SessionLocal(); records = db.query(DutyRecord).filter(DutyRecord.record_date == date.today()).all(); [print(f'id={r.id}, 班级={r.class_id}, 打卡={r.student_id}') for r in records]"` |
| **查看通知** | `python -c "from database import SessionLocal; from models import Notification; db = SessionLocal(); notis = db.query(Notification).all(); [print(f'id={n.id}, user={n.user_id}, 已读={n.is_read}, 内容={n.content[:30]}') for n in notis]"` |
